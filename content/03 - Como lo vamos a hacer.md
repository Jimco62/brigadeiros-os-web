# 03 - Cómo lo vamos a hacer (Flujo Diario)

## Flujo Actual - Después de la configuración del 31 Oct

1. Abrir Obsidian -> Vault `brigadeiros-alegria`
2. Escribir en:
   - `02 - Producto y Recetas` -> Nueva receta
   - `03 - Finanzas y Costos` -> Actualizar costo
   - `05 - Marketing y Redes` -> Idea de reel
3. Guardar `Ctrl + S`
4. Obsidian Git hace auto commit cada 10 min
5. Flechita morada `↑` aparece -> Click para Push a GitHub
6. Todo queda en `github.com/Jimco62/brigadeiros-alegria`

### Recuperar algo borrado
`Ctrl + P` -> `Git: Open history view` -> Buscar fecha -> Restaurar

### Cuando sea Fase 2 Web
1. Escribir idea en `05 - Marketing` en Obsidian
2. Diseñar en Canva con colores de `01 - Marca e Identidad/02 - Identidad Visual.md`
3. Subir a WordPress + Woo (sabores, precios de `04 - Web y Ventas`)
4. Programar en Meta Business Suite
5. Medir venta en `03 - Finanzas y Costos`

### Limpieza hecha
- Carpeta vieja `Brigadeiros Alegria` con espacio -> BORRAR
- Quedarse solo con `brigadeiros-alegria` con guión

### Comandos útiles
```bash
git status
git log --oneline
```
En Obsidian: `Ctrl + P` -> `Git: Open source control view`
