# 04 - Decisiones Técnicas - Por qué elegimos esto

## Decisión 1: GitHub + Obsidian vs solo Obsidian
**Decisión:** GitHub + Obsidian

**Por qué:** Obsidian solo guarda local. Si se rompe la PC, pierdes todo. GitHub da historial, nube privada y `Pushed 5 files to remote` verificable. Ya está hecho.

## Decisión 2: Node.js ¿Necesario?
**Decisión:** NO para Fase 1, SÍ solo si hacemos Quartz 4

**Por qué:** Instalaste `node-v26.13.0-x64.msi` pero para respaldo no hace falta. Se deja instalado por si en Fase 2 queremos blog técnico con Quartz. Si no, se puede desinstalar sin afectar nada.

## Decisión 3: Quartz 4 vs WordPress + Woo para web
**Decisión:** WordPress + WooCommerce para vender. Quartz solo opcional para blog/docs.

**Razón maestra:**
- Quartz = web estática, bonita, no cobra. Ideal para documentar, no para vender brigadeiros con delivery.
- WordPress + Woo = carrito, cupones, cálculo de envío SCZ, pago, WhatsApp automático, Pixel Meta para campañas.

Tu carpeta `04 - Web y Ventas` necesita Woo, no Quartz.

## Decisión 4: Redes Sociales - Herramienta adecuada
**Decisión:** Meta Business Suite (gratis) + Canva + CapCut + WhatsApp Business

**Por qué:** No pagar Buffer. Business Suite programa IG y FB a la vez. Canva usa tu identidad visual. WhatsApp Business es tu `04 - Web y Ventas`.

> Principio: Herramienta adecuada, no herramienta de moda.

## Decisión 5: Vault Intermedio (Este vault)
**Decisión:** Crear este Vault-Intermedio-Brigadeiros-OS separado del operativo.

**Por qué:** Tu vault operativo `brigadeiros-alegria` tiene recetas y finanzas. Este vault intermedio documenta el SISTEMA: qué queremos, con qué y cómo. Es el puente entre operación y tienda online. No se publica, pero guía la Fase 2.
